## 3. 갭 분석

1. **채널별 노출**: 블로그 10%(2/20, 공식 1건), 카페 0%(0/20), 지식iN 0%(브랜드명 노출 기준), 구글
   일반 검색 1페이지 0건 — 채널 전반에서 노출이 약함. 유일하게 강한 채널은 구글의 "로담 브랜드명 +
   키워드" 조합 검색(공식 사이트·이벤트 페이지 노출).
2. **경쟁사 대비 포지셔닝**: **후한의원**이 강남·전주·대전 등 다지점에서 "수두흉터" 지역 키워드 블로그를
   동시에 운영하며 롱테일 지역 검색을 분산 장악 중(기존 트래커 "가장 위협적" 평가와 일치).
   **밴스의원(thepetitshop 카페)**은 카페 채널을 사실상 독점.
3. **카테고리 인식**: 구글에서는 피부과(연세스타피부과)·전문가 매체(하이닥)가 정보성 콘텐츠를 장악,
   네이버에서는 한의원 간 경쟁(후한의원 vs 로담 vs 개인 시술 후기)이 중심 — 채널별 경쟁 구도가 다름.
4. **소비자 페인포인트 커버리지**: 지식iN에서 반복되는 질문은 "오래된 흉터도 치료 가능한가"
   "피부과 vs 한의원 중 어디가 나은가" "비용/횟수"로, brand.md의 "그들이 가진 문제" 항목을 채울 소스로
   활용 가능. 로담 콘텐츠가 이 질문에 직접 답하는 지식iN 노출은 확인되지 않음.
5. **리뷰 플랫폼**: 강남언니에 "수두흉터시술" 카테고리가 존재하나 로담의 등록 여부는 이번 조사로
   미확인(플랫폼 자체 접근 필요).
6. **검색량 규모**: "수두흉터치료"(월 100)는 "수두흉터"(월 850)의 12% 수준의 롱테일 — 콘텐츠 투자는
   "수두흉터"(및 "새살침" 9,640)처럼 더 큰 상위 개념어로 흡수시키는 전략이 유효해 보임(기존 경쟁사
   트래커의 "새살침" 상위 흡수 전략 노트와 일치).

## 4. 개선 제안 (우선순위)

1. **[최우선] 카페 채널 진입** — 밴스의원(thepetitshop)이 독점 중인 카페 채널에 로담 관련 콘텐츠가
   0건. 자사 후기단(체험단) 콘텐츠를 관련 뷰티/피부 카페에 노출시키는 전략 필요.
2. **[우선] 지식iN "닥톡" 답변에 로담 지점명 명시** — 새살침 코라테라피 용어는 이미 지식iN에서 인지도가
   있으나, 답변에 로담 지점명이 드러나지 않아 브랜드 귀속이 약함. 답변 콘텐츠에 지점명을 자연스럽게
   포함시키는 것을 검토.
3. **[검토] "수두흉터" 상위어로 콘텐츠 확장** — "수두흉터치료"보다 검색량이 8.5배 큰 "수두흉터"를
   메인 타깃 키워드로 콘텐츠를 흡수시켜 롱테일 대신 상위 트래픽을 노릴 것.
4. **[검토] 리뷰 플랫폼(강남언니/모두닥) 등록 현황 확인** — 구글에서 병원 추천 검색 시 이 플랫폼들이
   1페이지를 장악하므로, 로담의 등록·노출 여부를 별도로 점검할 것.

  조사로 "수두흉터" 키워드에서도 3개 지점이 동시 노출되는 패턴 재확인.
- **밴스의원(thepetitshop 카페)**: 기존 트래커에 "카페 독점형 경쟁 — 수두흉터, 상위 20건 중 17건
  독점"으로 기록됨. 이번 조사(카페 상위 20건 중 약 13건)로도 독점 패턴 재확인, 신규 경쟁사 아님.
