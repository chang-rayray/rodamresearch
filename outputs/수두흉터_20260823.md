# 키워드 시장조사: 수두흉터

- 조사일자: 2026-08-23
- 대상 브랜드: 로담한의원 (`_context/brand.md` 참고)
- 조사 채널: 네이버(블로그/카페/지식iN/지역검색/데이터랩), 구글(WebSearch)

## 1. 네이버 조사 결과

### 1-1. 블로그 — "여드름흉터제거"보다 로담 노출은 양호하나 경쟁 한의원도 강함
블로그 상위 20개 중 로담(또는 새살침) 관련 추정 콘텐츠가 다수 확인됨:
- **노원점 환자 후기 3건** (jiniyam1113: 노원/도봉구/상계동 — 모두 새살침 시술 회차 후기)
- **"새살침 알려주는 남자"**(mapobeehani) — 새살침 시술 전문 콘텐츠 채널
- **"[수두 흉터 치료] 한의원 새살침 후기"**(v_v_hi) — 결혼준비 신부 후기
- **대구 새살침 후기**(luvsa720)

→ "여드름흉터제거" 조사 때 공식 채널 0건이었던 것과 달리, "수두흉터"에서는 **새살침 키워드를 통해 실질적 노출이 형성**되어 있음.

다만 동시에 **경쟁 한의원 "후한의원"**이 강남점("20년의 노하우 후한의원 강남점" — 10년 된 흉터 치료사례)과 대전점("대전후한의원 문의경 원장 칼럼" — 자연치유 여부 콘텐츠)에서 **원장 칼럼 포맷**으로 신뢰도 높은 콘텐츠를 다지점에 걸쳐 생산 중. 로담의 노원점 콘텐츠는 환자 개인 후기 위주라 **원장/전문가 권위 콘텐츠 비중이 상대적으로 약함**.

### 1-2. 카페 — 경쟁사가 사실상 채널 독점, 로담 0건
카페글 상위 20개 중 **17건이 "밴스의원"(thepetitshop 카페) 자체 게시글**로, 유사한 제목("수두흉터 비용 후기 효과 부작용", "수두흉터제거수술 얼굴라인을 말끔하게…")을 반복 생산하며 키워드를 사실상 독점 중. 로담 관련 언급은 **한 건도 없음**. 블로그에서 확보한 존재감이 카페 채널에서는 전혀 이어지지 않음.

### 1-3. 지식iN — 직접 브랜드 노출은 없지만 "새살침" 용어가 일반 답변에 등장
20건 중 로담 브랜드명이 명시된 답변은 없으나, "닥톡" 상담의사 답변 등에서 **"새살침"이 흉터 치료 옵션으로 자연스럽게 언급**되는 사례가 확인됨(예: "얼굴의 수두흉터 때문에 새살침 치료를 받아볼까 합니다" 질문에 대한 답변). 이는 새살침이라는 고유 시술명이 어느 정도 업계 용어처럼 확산되고 있다는 신호이나, 동시에 **브랜드 연결 없이 일반명사화될 위험**(IP/상표 희석)도 내포함.

### 1-4. 지역검색 — 결과 자체가 희소, 로담 미노출
"수두흉터" 지역검색 결과는 단 **1건**(사월의봄 한의원)만 반환됨. 이 키워드는 로컬 검색 채널 자체가 미성숙하지만, 그 유일한 자리조차 로담이 아님.

### 1-5. 데이터랩 — 니치 카테고리, 하지만 브랜드 검색은 강세
- "수두흉터" 검색량은 "여드름흉터제거" 대비 **훨씬 작은 니치 카테고리**이며, 2026년 4월(15.9) 대비 8월(5.6)로 **약 65% 감소**(계절적 하락 패턴은 "여드름흉터제거"와 유사).
- "로담한의원" 브랜드 검색은 같은 기간 **28~100(6월 피크) 수준으로 견조**하며, "수두흉터" 키워드 자체보다 그룹 내 상대 비중이 훨씬 큼. 니치 흉터 타입임에도 기존 고객/인지도가 브랜드 검색을 뒷받침하는 것으로 추정.

## 2. 구글 조사 결과

### 2-1. "수두흉터" 순수 검색 — 로담 상위 10위 밖, 피부과·경쟁 제품이 점유
상위는 경향신문 뉴스, 강남언니 이벤트 페이지, 하이닥(전문가 칼럼 2건), 닥터나우, **연세스타피부과 블로그**, **drchin.co.kr의 "쥬브젠 자가진피 재생술"**(경쟁 시술 브랜드), 해외 보건 자료(NSW 정부)로 구성. 로담은 **전혀 노출되지 않음**.

### 2-2. "병원 추천 순위" 검색 — 로담 미노출, 강남언니·모두닥·연세스타피부과가 반복 노출
"여드름흉터제거"와 동일한 패턴 — 개별 병원보다 **플랫폼(강남언니 940개 병원, 모두닥 53.6만 리뷰)**이 관문 역할. 연세스타피부과가 이 키워드에서도 반복 노출되며 콘텐츠 권위를 쌓고 있음. 로담은 플랫폼에 등록되어 있음에도 검색 결과 표면에는 드러나지 않음.

### 2-3. 로담 자체 검색 — 다양한 채널에 분산 존재하나 파편화
- **여신티켓(Yeoshin)**: "수두흉터 새살침 5만원 이벤트" 페이지 확인 — 강남언니·모두닥 외 **제3의 예약/리뷰 플랫폼**에도 등록되어 있음
- **당근마켓**: 부산점 동네업체 프로필 존재 — 지역 커머스 채널까지 진출
- **공식 블로그(skincora.com)**: "수두 흉터는 왜 시간이 지나도 자연스럽게 없어지지 않나요?" — **키워드에 정면 대응하는 교육형 콘텐츠가 실제로 존재**함 (여드름흉터제거 조사 때는 이런 정면 대응 콘텐츠가 확인되지 않았음)
- 노원점 지점 페이지(skincora.com/branch/nowon.php)도 인덱싱됨

→ 콘텐츠 자체는 있으나 **여신티켓/당근마켓/공식블로그/지점페이지로 노출이 파편화**되어 있어, 정작 핵심 검색 결과(순수 키워드 검색, 병원 추천 순위 검색) 상위에는 어느 것도 랭크되지 못하는 상황.

### 2-4. 네이버 vs 구글 비교

| | 네이버 | 구글 |

| 직접 키워드 검색 | 블로그에 로담 콘텐츠 다수(새살침), 카페는 경쟁사 독점 | 로담 0건, 연세스타피부과·쥬브젠이 점유 |
| 지식iN/Q&A형 채널 | 브랜드명은 없지만 "새살침" 용어 확산 | 확인 안 됨 |
| 리뷰 플랫폼 | 해당 없음 | 여신티켓·당근마켓 등 등록 확인, 강남언니/모두닥 순위권 미확인 |
| 카테고리 인식 | 후한의원(경쟁 한의원)이 원장 칼럼으로 권위 구축 중 | "수두흉터=피부과 레이저/쥬브젠"으로 결과 형성 |

## 3. 종합 우선순위 제안

1. **카페 채널 공백 해소** — 밴스의원이 사실상 독점 중인 카페 채널에 로담/새살침 언급이 자연스럽게 실리도록 커뮤니티 활동 필요 (가장 시급, 여드름흉터제거 키워드의 지식iN 공백과 유사한 성격의 문제)
2. **"새살침" 브랜드 연결 강화** — 지식iN 등에서 시술명만 언급되고 브랜드가 빠지는 현상 모니터링, 답변/콘텐츠에 "로담한의원 새살침" 형태로 명확히 연결
3. **원장 칼럼형 권위 콘텐츠 제작** — 경쟁사(후한의원)의 "OO년 노하우", "10년 된 흉터 치료사례" 같은 스토리텔링 포맷을 참고해 로담 본점/노원점 외 지점에서도 유사 콘텐츠 확대
4. **구글 노출 파편화 정리** — 여신티켓·당근마켓·공식블로그·지점페이지에 흩어진 신호를 하나의 강한 랜딩 콘텐츠로 통합해 "수두흉터" 순수 키워드 및 "병원 추천 순위" 검색 상위 진입 시도
5. **지역검색(플레이스) 채널** — 결과 자체가 희소한 만큼 선점 시도 여지 있음
