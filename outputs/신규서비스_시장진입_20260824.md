## 4. 종합 분석

### 공통 패턴: 네이버 전 채널에서 로담 완전 미노출
3개 키워드 모두 블로그·카페·지식iN·지역검색에서 **로담 언급 0건**. 신규 서비스라 콘텐츠가 아직 축적되지 않은 것은 당연하지만, 문제는 **이미 여러 경쟁 브랜드가 카테고리별로 강하게 선점**하고 있다는 점.

### 경쟁 구도 지도
| 경쟁사 | 커버 카테고리 | 특징 |
|---|---|---|
| **생기한의원** | 편평사마귀, 모공각화증 | 노원·강남역·수원 다지점, 전용 카페(dnfdot) 운영 |
| **해율한의원** | 수두흉터, 새살침, 쥐젖, 지루각화증 | 전방위 카테고리 확장, 다지점(울산·목동 등) |
| **후한의원**(23지점) | 수두흉터, 새살침, 지루각화증 | 원장 칼럼 포맷으로 신뢰도 콘텐츠 생산 |
| **화접몽한의원** | 모공각화증 | 전용 네트워크 카페(samcclan) 운영 |

### 로담의 잠재적 차별화 포인트
공식 페이지(skincora.com) 확인 결과, 로담은 유일하게 **레이저 제거 후 "새살약침"으로 흉터를 최소화하는 연계 케어**(4CLEAR 시스템 4단계)를 갖추고 있음. 경쟁사 대부분은 "제거" 자체에만 집중하고 제거 후 흉터 케어 연계가 콘텐츠에 명시적으로 드러나지 않음 — 로담의 20년 흉터 치료 노하우를 살릴 수 있는 핵심 차별점.

### 우선순위 제안
1. **후발주자 콘텐츠 공백 긴급 해소** — 3개 키워드 모두 로담 0건인 상태를 방치하면 경쟁사(특히 다지점 브랜드)에게 카테고리 자체를 완전히 내주게 됨
2. **"제거 후 흉터 케어" 차별화 메시지를 콘텐츠 전면에 배치** — 경쟁사들이 갖추지 못한 유일한 강점
3. **"편평사마귀 성지" 문화에 대응** — 신뢰도 축적형 내돈내산 후기 콘텐츠(체험단 등)를 통해 "성지" 리스트에 진입 시도
4. **지역검색(플레이스) 최적화** — 9~10개 지점 보유에도 3개 키워드 전부 지역검색 미노출은 반복되는 구조적 약점 ([[여드름흉터제거]], [[수두흉터]], [[새살침]] 조사에서도 동일 패턴 확인)
5. **밴쿠버 지점 정보 확인** — brand.md 갱신 시 미해결로 남은 질문, 해외 진출 스토리도 콘텐츠 자산이 될 수 있음
