02

구글 조사

키워드 그대로 검색, 병원 추천 순위 검색, 브랜드+후기/단점 검색 3종 실행.

  • "수두흉터치료" 그대로 검색 — 상위 결과는 하이닥 전문가칼럼 2건, 연세스타피부과 블로그 3건이 주도. 로담 포함 한의원 콘텐츠는 1페이지 미노출.
  • "수두흉터치료 병원 추천 순위 2026" — 강남언니·모두닥 등 리뷰 플랫폼이 1페이지 상위 장악. 로담의 정식 등록·노출 여부는 이번 조사로 미확인, 별도 확인 필요.
  • "로담한의원 수두흉터 후기 단점" — 부정적 후기는 발견되지 않음. skincora.com(공식 도메인) 후기 페이지, 여신티켓 이벤트 페이지("수두흉터 새살침 5만원 이벤트")가 노출되어 공식 채널의 구글 인덱스 자체는 확인됨.
03

갭 분석

  1. 채널별 노출 — 블로그 10%(2/20), 카페 0%, 지식iN 브랜드명 노출 0%, 구글 일반 검색 1페이지 0건. 유일하게 강한 지점은 구글에서 "로담 브랜드명 + 키워드" 조합 검색 시 공식 사이트·이벤트 페이지 노출.
  2. 경쟁사 대비 포지셔닝 — 후한의원이 강남·전주·대전 다지점에서 동시에 "수두흉터" 지역 콘텐츠를 운영. 밴스의원(thepetitshop 카페)은 카페 채널을 사실상 독점.
  3. 카테고리 인식 — 구글에서는 피부과·전문가 매체(연세스타피부과, 하이닥)가 정보성 콘텐츠 장악, 네이버에서는 한의원 간(후한의원 vs 로담) 경쟁이 중심 — 채널별 경쟁 구도가 상이함.
  4. 페인포인트 커버리지 — 지식iN 반복 질문("오래된 흉터도 되나요", "피부과 vs 한의원", "비용/횟수")에 로담이 직접 답하는 노출은 확인 안 됨. brand.md의 "그들이 가진 문제" 항목 보완 소스로 활용 가능.
  5. 리뷰 플랫폼 — 강남언니 "수두흉터시술" 카테고리 존재, 로담 등록 여부 별도 확인 필요.
  6. 검색량 규모 — "수두흉터치료"(100)는 "수두흉터"(850)의 12% 수준 롱테일. 콘텐츠 투자는 더 큰 상위 개념어("수두흉터", "새살침")로 흡수시키는 전략이 유효.

개선 제안

01
최우선

카페 채널 진입

밴스의원(thepetitshop)이 독점 중인 카페 채널에 로담 관련 콘텐츠가 0건. 관련 뷰티/피부 카페 대상 체험단 콘텐츠 노출 전략 필요.

02

지식iN "닥톡" 답변에 지점명 명시

새살침 코라테라피 용어는 이미 지식iN에서 인지도가 있으나 답변에 로담 지점명이 드러나지 않아 브랜드 귀속이 약함. 답변에 지점명을 자연스럽게 포함시킬 것.

03

"수두흉터" 상위어로 콘텐츠 확장

검색량이 8.5배 큰 "수두흉터"를 메인 타깃으로 콘텐츠를 흡수시켜 롱테일 대신 상위 트래픽을 확보.

04

리뷰 플랫폼 등록 현황 확인

구글 병원 추천 검색에서 강남언니·모두닥이 1페이지를 장악하므로 로담의 등록·노출 여부를 별도 점검.

05

경쟁사 대조

memory 경쟁사 트래커 대조 결과

  • 후한의원(강남·전주·대전 등) — 기존 트래커에 "가장 위협적" 다지점 네트워크로 이미 기록. 이번 조사로 "수두흉터" 키워드에서도 3개 지점 동시 노출 재확인.
  • 밴스의원(thepetitshop 카페) — 기존 트래커에 "카페 독점형 경쟁 — 수두흉터 상위 20건 중 17건 독점"으로 기록. 이번 조사(약 13/20)로도 독점 패턴 재확인, 신규 경쟁사 아님.
  • 신규 확인: 미올한의원(김포), 더웰니스의원, 르샤인의원 — "수두흉터" 카테고리에서 처음 노출. 추가 확인 후 트래커 반영 제안.
