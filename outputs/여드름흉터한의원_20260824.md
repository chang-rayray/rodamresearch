| **소비자가 이미 성분/근본원인("다운타임 없이", "붉은자국 동시개선")을 검색으로 찾고 있음** | 카페·지식iN 반복 질문 패턴 — 로담의 "피부 재생력 기반 영구 복원" 메시지와 직접 부합 |
| **리뷰 플랫폼 랭킹 콘텐츠가 구글 상위를 장악** | 강남언니/모두닥 총론 페이지가 "추천 순위" 검색을 이미 차지 — 로담이 플랫폼 내부 SEO(이벤트 제목에 키워드 포함 등)만 보강해도 별도 채널 구축 없이 상위 노출 가능 |

### Threats (위협) — 방치하면 로담에게 불리해지는 것

| 위협 | 근거 |
|---|---|
| **해율한의원의 "오름침" 용어 전유 시도** | [[project-competitor-tracker]] 기록 — 새살침 개념을 자사 시술명으로 재브랜딩하며 원조 포지션을 흐림 |
| **후한의원의 규모 경쟁(전국 20개 지점 자칭)** | 지점 수 메시지에서 로담(9개)을 앞서는 서사 구축 중 |

## 4-1. SWOT 교차 전략 (TOWS)

- **SO (강점으로 기회를 잡기)**: 원조 특허(S)를 지식iN 빈 채널(O)에 "새살침 원조가 답하는 Q&A" 형태로 심어 카테고리 선점 콘텐츠로 전환.
- **ST (강점으로 위협을 막기)**: 8만 건 시술 실적·7회 1등급 만족도(S)를 "용어 전유 시도"(T) 대응 콘텐츠에 정면 배치 — "새살침 원조는 로담"을 데이터로 재확인시키는 비교 콘텐츠.
- **WO (약점을 보완해 기회를 잡기)**: 체험단 연재 부재(W)를 카테고리 우호적 지형(O)에 맞춰 지점별 앰버서더 블로거 계약으로 즉시 보완 — 진입장벽이 낮은 지금이 적기.
- **WT (약점과 위협이 겹치는 구간, 최우선 방어)**: 커뮤니티 침투 0건(W) + 반복연재 독점화(T)가 겹치는 acnescar(피부인) 카페가 가장 시급한 방어선 — 방치 시 회복 비용이 계속 상승하는 구간이므로 최우선 착수.

## 5. 우선순위별 개선 제안

1. **(최우선, WT) 카페·지식iN 콘텐츠 공백 메우기** — acnescar(피부인), suddes(병원발품) 등 이미 이 키워드로 트래픽이 몰리는 커뮤니티에 해율한의원식 "체험단 연재" 포맷으로 지점별(강남/잠실/홍대/노원 등) 후기를 심을 것. 현재 이 채널에서 로담 언급이 0건인 것이 가장 큰 손실 구간이자, 경쟁사가 이미 독점화를 진행 중인 위협 구간.
2. **(WO) 다회차 체험단 반복 노출 전략 벤치마킹** — 해율한의원처럼 동일 블로거가 1회차→마지막회차까지 연재하는 방식은 검색 결과 페이지를 사실상 독점하는 효과가 있음. 로담도 지점별 앰버서더 블로거를 통한 회차별 연재를 강화할 것.
3. **(SO) 지식iN 원조 포지션 선점** — 브랜드명이 전무한 지식iN 채널에 "새살침을 최초 개발한 곳이 직접 답하는" 형태의 콘텐츠를 심어 원조성을 카테고리 표준 답변으로 만들 것.
4. **(WO) 소비자 불만(비용·다운타임·회차) 선제 대응 콘텐츠** — 구글 검색에서 확인된 "이벤트가 이후 추가금", "통증/다운타임", "5회 이상 필요" 불만을 자사 채널에서 투명하게 설명하는 FAQ형 콘텐츠 제작. 신뢰 형성 + 이탈 방지 목적.
5. **지역 롱테일 키워드 커버리지 점검** — 지역검색(local) 결과에서 로담은 부산점 1건만 확인됨. "강남역/잠실/홍대 여드름흉터한의원" 등 지점별 롱테일 키워드에서 실제 노출 순위를 별도 조사할 필요.
6. **(SO) 리뷰 플랫폼 노출 강화** — 등록은 되어 있으므로, "여드름흉터한의원 추천 순위" 같은 구글 상위 노출 쿼리에 걸리도록 플랫폼 내 이벤트/콘텐츠 페이지의 SEO(제목에 키워드 포함 등)를 점검.
