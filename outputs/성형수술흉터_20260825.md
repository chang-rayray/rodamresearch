- **5건 전부가 한의원이 아닌 성형외과**라는 점 자체가 이 키워드의 카테고리 인식을 가장 명확히 보여줌.

### 1-5. 데이터랩 (검색량 추세) — 실패, 절대 검색량으로 대체

- `datalab_search` API 인증 실패(HTTP 401, errorCode 024) — 여드름흉터한의원 조사 때와 동일한 오류. 네이버 개발자센터 앱의 "데이터랩(검색어트렌드)" API 활성화 여부 확인 필요.

## 4. 우선순위별 개선 제안

1. **(최우선) 카테고리 자체의 구조적 열세 인정 — "비수술 대안" 포지셔닝으로 차별화** — 이 키워드는 성형외과가 이미 전문의 실명 콘텐츠(지식iN)와 세부 흉터별 전문성(블로그)으로 카테고리를 장악한 상태. 정면 경쟁보다 "수술을 이미 했고 흉터가 남은 사람 → 재수술 없이 한방으로 개선"이라는 명확한 대안 포지셔닝이 필요.
2. **지식iN 빈 채널 공략** — 소비자가 반복 묻는 "흉터가 언제 안정되나", "붓기·통증 외 부작용" 질문에 성형외과 전문의만 답하는 구조. 로담이 "수술 후 흉터가 남았을 때 비수술적 선택지"로 답변형 콘텐츠를 심을 여지가 있음(단, 지식iN 마케팅 답변의 의료광고법 준수 필요).
3. **"새살침" 브랜드 연결고리 점검** — 블로그 2위 "새살침 알려주는 남자" 콘텐츠가 로담 공식/제휴 채널인지 확인 필요. 공식이 아니라면 새살침이라는 자사 고유명사가 제3자 채널에서 브랜드 연결 없이 소비되고 있다는 뜻 — 소유권 있는 콘텐츠로 흡수하거나 별도 대응 검토.
4. **소비자 불만(총비용·치료기간·효과 체감) 선제 대응 콘텐츠** — "여러 번 해야 해서 총비용 부담", "가격 대비 효과 기대 이하" 불만이 확인됨. 여드름흉터 조사에서도 동일 패턴(다회차 부담)이 나왔던 만큼, 카테고리 공통 FAQ로 통합 제작 검토.
5. **진성형외과(drchin.co.kr) 재확인** — 수두흉터에 이어 성형수술흉터 지역검색에서도 노출. 흉터 카테고리 전반의 반복 경쟁자로 별도 모니터링 필요.

## 5. 경쟁사 트래커 대조

기존 [[project-competitor-tracker]]에 기록된 진성형외과(drchin.co.kr)가 이 키워드에서도 재확인됨. **신규 경쟁사**(흉터 전문 성형외과 진영, 트래커 추가 검토 필요):

- **아문성형외과**(서울 강동구) — 흉터레이저+주사 콤보, 자체 공식 카페 운영
- **그림성형외과**(구상환 원장) — 구순열흉터 30년 전문, 블로그 시리즈 연재
- **함희정성형외과** — 흉터제거 전문 포지셔닝
- **시우성형외과** — 코수술 흉터 케어 콘텐츠, 자체 공식 카페 운영
- **연세스타피부과** — 기존 트래커에 여드름흉터·수두흉터로 기록되어 있었으나, 갑상선수술흉터 레이저 콘텐츠에서도 확인되어 흉터 카테고리 전반 커버리지 재확인
