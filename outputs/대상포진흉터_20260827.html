확정 노출 0건 / 20건

상위 20건 중 로담 공식 채널(skincora.tistory.com) 게시물이 3건 노출되지만 전부 다른 흉터 키워드(수원패인흉터, 강남수두흉터, 노원구얼굴패인흉터)를 타겟한 글이 우연히 매칭된 것으로, 대상포진과는 무관하다. 나머지는 잡티 제거·헤르페스 연고 등 무관 콘텐츠로 채워짐.

참고

"로담한의원 대상포진"으로 재검색하면 결과가 완전히 달라진다 — 천안대상포진흉터제거수술(2021), 부산대상포진흉터없애기(2021), 구로피부과 수두흉터, 대상포진흉터 치료 핵심 포인트(2024, 가산금천점) 등 10건 이상. 콘텐츠는 충분히 많지만 "대상포진흉터" 단독 키워드 최적화가 안 되어 순수 검색에서 묻힌다.

02

구글 조사

"대상포진흉터 치료 병원 추천" 검색 결과는 대부분 정보성 콘텐츠(닥터나우 Q&A, 서울대병원, 마취통증의학과·신경과 중심 병원)로 채워지고, 피부과가 "일반적" 선택지로 언급될 뿐 한의원 카테고리 콘텐츠는 상위에 없다. 로담을 포함한 어떤 한의원도 구글 상위 노출에서 확인되지 않음.

"로담한의원 대상포진흉터 후기 단점" 검색에서는 브랜드 자체(강남언니 잠실점, 공식 사이트 skincora.com/rodamblog.com, 여신티켓 강남점 정동빈 원장)는 인덱싱되어 있으나, 대상포진흉터 특화 후기·단점 콘텐츠는 별도로 검색되지 않았다 — 네이버 카페/블로그 자산이 구글 인덱스로는 잘 노출되지 않는 것으로 보인다.

03

갭 분석

  • 채널별 노출: "대상포진흉터" 단독 키워드 기준 전 채널 확정 노출 0건. "로담한의원 대상포진" 검색에서는 콘텐츠 풍부 — 콘텐츠 부재가 아니라 키워드 타겟팅/SEO 실패가 원인.
  • 경쟁사 포지셔닝: 강력한 단일 경쟁사는 없으나, 온바디한의원(여드름흉터+한방가슴성형 겸업)이 검색 유입용 콘텐츠 생산 중. 흉터 전문성보다 종합 한방 브랜드로 보임.
  • 카테고리 인식: 구글에서 대상포진흉터 치료는 "피부과/신경과/마취통증의학과" 영역으로 인식되며, 한의원 카테고리는 검색 결과에 거의 등장하지 않음.
  • 페인포인트 커버리지: 카페·지식iN 고민은 "급성기 흉터 예방"과 "이미 남은 흉터 치료" 두 단계로 나뉜다. 로담 콘텐츠는 후자에 집중되어 있고 전자(급성기 예방 팁)는 확인되지 않음.
  • 리뷰 플랫폼: 강남언니에 잠실점 등록 확인, 대상포진흉터 전용 태깅 여부는 미확인.
  • 검색량 규모: 1,040건/월의 중소형 롱테일. 신규 제작보다 기존 글 리라이팅이 투자 대비 효율이 높음.
04

개선 제안

01
최우선

기존 콘텐츠 SEO 리프레시

skincora.tistory.com·smtibm·acnescar 카페에 이미 존재하는 대상포진흉터 치료 사례 10건 이상의 제목·첫 문단에 "대상포진흉터"를 명시적으로 배치해 재발행/업데이트. 신규 제작보다 비용 대비 효과가 큼.

02

급성기 관리 콘텐츠 신설

"대상포진 수포·딱지 관리 중 흉터 최소화하는 법" 등 예방 단계 콘텐츠로, 카페/지식iN 급성기 고민 검색 유입을 흉터 치료 잠재고객으로 조기 연결.

03

지식iN 답변 활동

순수 "대상포진흉터" 질문에 로담 원장 명의 답변 전무 — "코라테라피" 상표 키워드에서도 경쟁사(나비한의원)가 대신 답변하는 것과 동일한 취약 패턴. 채널 방어 시급.

04

데이터랩 API 권한 확인

프로젝트 자체 네이버 API 키의 데이터랩 스코프 미부여로 401 오류 반복 — 네이버 개발자센터에서 활성화 여부 확인 필요.

05

경쟁사 대조

기존 트래커 재확인: 밴스의원(thepetitshop 카페, 기존 수두흉터 독점 기록 — 대상포진흉터 콘텐츠도 확인되어 카테고리 확장 필요), 피부인(acnescar) 카페(중립 커뮤니티이나 로담 자체 콘텐츠가 다수 게재되어 로담에 유리한 채널).

신규 경쟁사 제안

온바디한의원 — 여드름흉터한의원 + 한방가슴성형 + 한약다이어트를 겸업하는 종합 한방 브랜드. 자체 카페(cafe.naver.com/alstj5646)에서 "대상포진흉터", "새살침" 등 흉터 키워드를 낚시성 제목으로 스터핑하는 패턴 확인. 흉터 전문성은 로담·후한의원 대비 낮아 보이나 검색 유입 전략은 참고할 만함.
